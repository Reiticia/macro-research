# 财报解析共享样例

Rust 与 Android 测试读取同一份 JSON。字段结构依据公开 Nasdaq 日历和 TradingView scanner 响应；样例包含合成公司和边界值，不作为真实投资数据。

- `nasdaq.json`：未来预期字段、盘前/盘后/未知、缺失值、负数、实际 EPS 为零和分析师数量为零。
- `logo.png`：代码生成的 1×1 PNG，仅用于图片校验与转发测试，不包含真实公司商标。
- `tradingview.json`：按请求列顺序排列的值、十进制预测、下一次日期冲突及营收缺失。时间戳只用于提取美东日期。

LOSS 已有实际 EPS，因此不得把 scanner 的下一期预测合并到该已披露记录。独立解析仍可验证日期冲突标记。
