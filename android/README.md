# Macro Research Android

宏观财经事件研究客户端。默认直接访问公开数据源，也可以只依赖一台自建后端
（见 [后端说明](../docs/backend.md)）。

## 数据来源模式

设置页顶部的「数据来源」卡片可以在两种模式间切换，**默认直连**：

- **直连**：设备直接请求 TradingView / CNBC / Yahoo / BiQuote / Binance，可选 HTTP 代理；
  AI 分析与翻译使用你自备的 OpenAI 兼容 Key。
- **后端**：只请求你的服务器（地址 + 访问令牌），数据、译名与 AI 简报均由服务端提供，
  无需个人 Key，并可通过 WebSocket 接收事件公布提醒。

后端可以是 `https://你的域名`（后端自己出证书，或用 Caddy/Nginx 反代），也可以是内网 / 隧道
地址（如 Tailscale 的 `100.x.y.z`）——后者需在设置页显式勾选「允许明文 HTTP」，因为令牌会以明文
传输；公网地址一律要求 https。

切换模式会清空本地事件缓存与关注列表（两种模式使用不同的事件标识），筛选设置保留，
切换前会弹框确认。后端不可达时只显示缓存并给出明确错误，不会静默改走直连。

## 功能

- 五个一级导航：首页、日历、市场、历史、设置。
- 财经日历优先获取 BiQuote，失败或无数据时依次回退 TradingView、Forex Factory 并写入 Room。BiQuote 按日请求并拆分达到 500 条上限的窗口，避免截断；直连时优先 IPv4，持续网络失败使用持久化熔断，各源遵守独立的 `Retry-After` 限流窗口。
- 客户端直接从 Yahoo Finance、Binance、BiQuote、CNBC 获取实时行情和可用的分钟 K 线。
- 在设备端计算 Actual / Consensus 预期差、规则信号、理论影响和实际行情窗口。
- 事件公布后可用自有 AI 接口生成市场分析：传导链路（数据意外 → 利率/美元/风险资产）、数据解读与走势判断，结果存入 Room，可随时重新生成。个人 AI 分析可选从用户配置的 HTTPS RSS/Atom 源获取相关新闻元数据；默认源为 MarketWatch、BBC Business、DW，后端共享 AI 不使用此功能。
- 首页下一重要事件、秒级倒计时、今日事件和市场概览。
- 七日选择、重要性与国家筛选的财经日历。
- 历史研究与日历共用高 / 中 / 低重要性多选筛选，默认全选且至少保留一项，可与分类、国家组合使用；列表分页与统计卡片同步应用筛选条件，切换筛选会回到最新记录。
- 所有成功获取的事件都会合并入 Room；历史页每次从最新 8 条开始，滑到列表底部自动从数据库加载再早 8 条，本地事件最长保留 730 天。公开行情超出保留期时明确显示缺失，不使用当前价格伪造历史数据。后端模式下历史分页直接请求服务端。
- 所有时间按设备系统时区展示，每日区间（日历、首页今日、历史同步窗口）也按同一时区划分。
- Room 离线缓存与本地关注状态。
- English / 简体中文 / 繁體中文界面。
- 后端模式下的事件公布本地通知（应用运行时）。

## 应用更新与本次更新说明

设置页「应用更新」显示版本、手动检查、自动检查开关和上次成功检查。正式版默认每 24 小时前台检查一次，Debug 默认关闭；直连 GitHub，不使用日历代理、后端令牌或个人模型。不运行后台定时任务，失败不影响日历，GitHub 不可达时可重试或打开发布页。只接受完整正式统一 Release，旧版没有清单的 Release 不算可更新版本。

确认后使用 Android DownloadManager 下载 APK，支持后台继续、前台进度、取消/重试。下载后校验大小、SHA-256、包名、版本、系统要求和签名，用户再确认安装；不会静默下载/安装，不申请存储权限。正式 APK 通常不能覆盖 Debug 签名，校验失败不会卸载或清除数据。

全新安装或升级后第一次打开，离线展示当前版本三语更新说明；点击「知道了」后不重复弹出，设置页可重看。说明来自 `android/release-notes/<versionName>.json` 并在构建时打包，版本/三语缺失会导致构建失败；确认记录不参与备份。

正式发布和维护说明见 [统一 Release](../docs/github-release.md)：`vX.Y.Z` Tag 自动构建并发布同提交 APK 和 Linux 后端，已发布附件不允许覆盖。实现功能后正式发布前需另行递增客户端版本并新增对应三语说明。

## 翻译与 API Key

直连模式下应用默认固定为英文。设置页提供：

- OpenAI 兼容 API Key
- HTTPS API endpoint
- 模型名称

只有成功保存非空 Key（或处于后端模式）后，简体中文和繁體中文选项才可选择。事件名称由客户端直接调用用户配置的翻译接口；每批翻译完成后会再次交给模型校对，确认无误才会入库，未通过的条目会自动重译。翻译失败不会影响日历和行情数据。

事件名勘正：直连模式立即在本机生效；后端模式提交给服务器，由管理员在 Telegram 上审核后对所有设备生效。

设置页「数据来源」的 API Key 旁提供「获取 API Key」按钮：填写后端地址后即可打开该后端配置的 Telegram 机器人，无需先保存设置或已有 Key。未安装 Telegram 时可用浏览器打开；后端需支持公开 `/api/v1/access-key-bot` 接口，未配置机器人或不可达时会提示错误。

后端 API Key 在 Telegram Bot 私聊通过 `/request_key device` 或 `/request_key general` 申请，经管理员批准后发放。通用 Key 不绑定设备；设备 Key 首次成功授权时绑定安装 UUID + ANDROID_ID 摘要，清除数据/卸载后需重新申请。设置页「测试连接」先调公开的 `/api/v1/meta` 校验地址、证书与内部协议兼容性，再匿名探测 `/api/v1/status` 确认鉴权开启，最后带 Key 请求该受保护接口；只有最终鉴权成功才显示通过，有效设备 Key 在此可能首次绑定。测试强制联网、不缓存；不返回或显示后端软件版本号，但保留后端 AI 分析已开启/未开启的状态，不为检查状态调用模型。

安全措施：

- APK 与源码不包含用户 Key，也不内置后端地址与令牌。
- Key 与后端令牌使用 Android Keystore 的 AES-GCM 密钥加密后写入独立 SharedPreferences。
- 密钥文件排除云备份和设备迁移。
- 翻译 endpoint 默认必须使用 HTTPS，且不能包含用户信息、查询参数或 fragment；后端地址仅在内网/隧道 + 显式开启时才允许 HTTP。
- 调试日志只记录 HTTP BASIC 元数据，不记录 Authorization header。
- 建议使用有权限范围和消费限额的个人模型 Key；后端 Key 通过 Bot 申请并批准，可单独撤销。安装 UUID、后端凭据排除云备份与设备迁移；只向配置的后端发送 UUID 和应用域分隔的 ANDROID_ID SHA-256，不发送原始 ANDROID_ID，也不发给公开源/个人模型。设备标识不是不可伪造的硬件证明。

## 第三方数据源

直连模式只包含公开第三方服务入口，不包含自有服务器地址：

- `economic-calendar.tradingview.com`：财经日历（主源，免 Key JSON 接口）
- `nfs.faireconomy.media`：Forex Factory 本周财经日历（回退源，免 Key JSON）
- `query1.finance.yahoo.com`：传统市场行情
- `data-api.binance.vision`：Binance 公共加密资产行情
- `biquote.io`：外汇与贵金属行情
- `quote.cnbc.com` / `ts-api.cnbc.com`：美债收益率与 1 分钟 K 线（主源）

第三方服务可能限流、调整页面结构或缩短历史数据保留期。应用使用本地缓存、逐源降级和明确缺失状态，但不能保证第三方长期可用。使用时应遵守对应服务条款。
