## 判定

1. 按来源和稳定系列ID解析统一系列键，不用单次occurrence ID当系列ID。
2. 国家和精确标题也必须与已观察元数据一致，标题变更（尤其新增s.a./Final等口径）拒绝，不仅凭旧系列ID放行。
3. 映射是固定月度系列，统计期必须两边均可解析且相同；不从公布月份猜测统计期。
4. 精确UTC时刻完全相同，纳秒差异不截断；两边`timeExact=true`。
5. 百分比单位仅允许 `%` / `percent`；未知单位或倍率/维度变化拒绝。
6. 同一系列/统计期/时刻有多候选时只记录歧义，不任选一条。

名称差异由固定目录对应，不做编辑距离、向量或AI模糊判断。所有新映射都只输出影子记录，不能绕过原生产规则。
