# BiQuote 市场新闻

## 接口核对

核对日期：2026-10-29；公开文档：https://biquote.io/docs/#news 。

```bash
curl -G 'https://biquote.io/api/news/market' \
  --data-urlencode 'language=en' \
  --data-urlencode 'country=US' \
  --data-urlencode 'maxResults=50'
```

无需 API Key，返回裸 JSON 数组。文档参数：

| 参数 | 含义 |
|---|---|
| `symbol` | 可选股票／资产代码，如 AAPL、XAUUSD；不能据此保证每条新闻严格相关 |
| `language` | 新闻语言，默认 en |
| `country` | 新闻版本／编辑区域，默认 US；不是日历的 countries 参数 |
| `maxResults` | 1–50，默认 10 |

字段为 `title`、`description`、`url`、`publisher`、`publishedDate`、`imageUrl`、`category`、`language`、`country`。实测 `publishedDate` 为带 Z 的 UTC 时间，language/country/imageUrl 可能为空。Google News 条目的链接可能是聚合跳转地址，description 可能拼接多家媒体的标题，不能当成原文正文。

文档说明聚合 Google News 与部分 Hacker News 报道。默认请求中能看到美联储决议报道；XAUUSD 查询实测仍混有科技财报等泛市场新闻，且可能返回数周前文章。接口没有已文档化的日期区间、历史分页或宏观事件 ID 搜索，不能充当历史新闻库、可靠的逐事件检索或利率预期源。

## 本次接入：个人 AI 新闻背景

入口：设置 → 个人 AI 新闻背景 → 在分析中加入相关新闻 + 加入 BiQuote 市场新闻。两个开关均需开启；BiQuote 默认关闭，升级不改变现有 RSS 的授权范围。只使用 BiQuote 时，将 RSS 地址框清空后保存即可；空 RSS 列表会保留，重启不恢复默认源。新闻总开关开启时至少需要 BiQuote 或一个有效 RSS 源。

- 在已有 RSS 新闻流程中增加可选 JSON 新闻源，不新增资讯页面、后台轮询、后端路由或数据库表。
- 固定读取英文美国版，避免把 UI 语言或日历国家直接当作新闻 API 支持的参数，也不把事件数据发送给上游。
- 仅用户生成／重新生成个人 AI 分析时读取；无个人 Key、读取已有分析缓存都不会调用。新闻也不发送到后端；后端共享 AI 已移除。
- 新闻请求有独立短超时和 512 KiB 响应限制；不自动重试，失败不阻断 RSS 或个人 AI，状态区分失败、部分成功、无相关结果。
- 默认只解析元数据；另有独立、默认关闭的“允许 AI 读取文章预览”开关，需同时开启新闻背景及 AI 只读函数调用。启用后模型可用 open_news_article(articleIndex) 读取本次已筛选新闻的静态页面文字，不接受任意 URL。拒绝非 HTTPS／含账号密码的文章链接，标题／来源／摘要限制长度。
- RSS 与 BiQuote 合并后，只有精确时间事件、发布时间可解析且位于事件前后 24 小时、不晚于分析请求时刻的新闻才可入选。按标题关键词评分，不从聚合摘要中猜关联；同分时优先新报道，按 URL 去重，总计最多 8 条。
- 关键词仅为启发式背景筛选，不保证国家或事件关联；两阶段方法的第一阶段继续不含新闻，新闻仅在第二阶段作有日期和来源的背景。模型明确不得遵循新闻内指令、编造缺失数值或将报道当成因果证明。
- 新闻源直连，不继承日历专用代理，不携带后端令牌或设备标识。文章元数据和获准读取的页面文字会被发送到用户自行配置的个人 AI endpoint，设置已明确告知。
- 页面预览使用独立、无 Cookie／无凭据客户端，不执行 JavaScript、下载子资源、登录或绕过付费墙。只允许公网 HTTPS/443，DNS 返回私网、环回、链路本地、组播或特殊保留地址时拒绝，重定向及原文交接逐跳校验，最多 4 次。普通媒体页面响应最多 512 KiB，Google News 文章壳页单独限 1 MiB（不能作为正文）；总时限 20 秒、提取文本最多 6000 字符；每阶段最多两篇不同文章，重复选择复用本次结果，仍受总工具轮数和次数限制。
- 调用链显示新闻源请求链接及文章实际请求／重定向的链接、HTTP 状态、耗时和结果，敏感查询参数脱敏，随事件本地保存。页文可能包含更新后的信息、导航、登录或付费提示，不证明事件关联或当时的完整内容；Google News 文章壳页通过页面 article ID／时间戳／签名向固定的公开 batchexecute RPC 请求媒体原文 URL，再校验公网页面策略后访问，不执行脚本。此为非稳定的上游协议，不保证长期可用。调用链单独显示解析请求与原文链接，并区分原文解析失败、HTTP 拒绝、大小超限和没有静态文本；即使原文 URL 解析成功，CNBC 等站点仍可能返回 403。不会将 Google 壳页、Access Denied 或错误页当作正文。
- 关闭预览不再向模型提供文章工具，也不额外访问文章；已保存请求中的旧预览不会自动删除。预览只接入生成／重新分析，追问暂不提供此工具。

主要代码：

- `android/.../data/remote/BiquoteNewsClient.kt`：有界、可取消的 JSON 获取与字段适配。
- `android/.../data/remote/NewsRssClient.kt`：并发聚合、时间范围与标题筛选。
- `android/.../data/NewsPreferences.kt`、`ui/settings/NewsContextSettings.kt`：独立 opt-in。
- `android/.../data/MacroRepository.kt`：仅个人 AI 生成路径接入。

## 适合后续增加的用途（尚未实现）

1. **行情页市场快讯**：最符合该接口的实时聚合性质；须展示媒体、发布时间、链接和加载／错误状态，可按资产查询但仍需提示弱相关。
2. **事件详情的相关报道**：仅展示同一时间窗口内的候选背景，与日历数据分区；不能承诺精确关联，也不能用当前报道填充旧事件。
3. **FOMC 等文本型事件背景**：作为声明／发布会的辅助阅读，不能由标题提取官方利率值或补预测值。

若未来加入后端模式新闻页，应先独立设计后端抓取缓存、显式代理路由、限流和错误契约，不允许客户端在后端故障时偷偷直连。后端不再提供 AI 分析，不能复用客户端新闻启动后端模型调用。
