# 公布值即时方向标签

Android 的即时判断仅在事件详情展示，直接读取 Room 中的事件快照；不等待 AI、行情采集或规则分析报告。直连与后端模式均支持，规则报告及 AI 分析仍保持原有语义。

## 展示与排版

- 首页、日历、关注、历史的事件列表保留名称、时间、国家、重要性、状态及前值、预期、已获取的公布值；预期优先使用有效市场预期，缺失时回退预测值。首页下一事件摘要保留前值、市场预期和预测值，不展示偏差或资产方向。
- 详情数值卡保持在倒计时下方，按原有顺序横向展示“实际值 / 市场预期 / 预测值 / 前值”，不合并重复的预期值或移动前值。
- 在事件介绍后、市场关注前独立展示“标的影响程度”单列列表，每行显示标的名称、规则方向及影响程度（无明显影响 / 影响有限 / 影响较明显）。大字体／窄屏时同一行的内容上下排列，标的仍为单列。偏差和阈值保持可见，完整依据与风险说明可展开；没有公布值或可靠规则时仅显示缺失原因，不伪造标的影响。

## 判断依据

- 比较基准：有效的 `consensus` 优先，否则使用有效的 `forecast`，不使用前值。
- 美国主要指标使用单项数据的政策预期基准：偏鹰通常支撑美元指数和美债收益率，压制黄金、纳指、比特币；偏鸽反向。失业率及初请人数采用反向规则。
- EIA 原油库存仅推导 WTI、Brent 方向。美债标签表示**收益率**，不是债券价格。
- 差距为零：符合预期、无明显方向。非零但低于阈值：保留方向并显示“影响有限”；达到阈值：显示利多／利空（规则预期）。
- 缺少公布值、有效预测、可靠规则或明确单位时分别显示原因，不能当成中性。
- 使用英文原始名称和明确别名匹配，不受中文译名影响；不把 ADP、ISM 价格／就业等分项误认作主指标。

默认阈值由 `android/app/src/main/java/com/macroresearch/data/ReleaseImpactRules.kt` 集中维护：

| 指标 | 明显偏差起点 |
|---|---:|
| CPI／PCE／PPI（含核心）、平均时薪、失业率 | 0.1 个百分点 |
| 非农就业变化 | 50,000 人 |
| 初请失业金人数 | 10,000 人 |
| GDP 增长率 | 0.5 个百分点 |
| ISM 制造业／服务业 PMI | 1 指数点 |
| 美联储利率决定 | 0.25 个百分点 |
| EIA 原油库存变化 | 1,000,000 桶 |

这些是首版可维护的启发式默认值，未经历史误差统计校准，**不代表实际行情幅度或确定性**。详情展示比较基准、标准化偏差、阈值及说明。百分率按百分点比较；明确的千／百万单位按尺度换算；Forex Factory 已展开的数值不重复换算。TradingView 来源明确的独立 `scale`（K/M/B/T）与 `unit` 合并保存；保留展示尺度数值，影响计算只乘一次倍率，不混用 `*Raw`。来源单位和倍率都缺失时不按事件名猜千人、百万桶等倍率，保留“单位不明确”。Forex Factory 的 K/M/B/T 字符串在解析时展开一次并标记为 `number`（绝对数量）；后缀本身不代表货币。影响计算仅在已有规则确定物理维度且尺度已明确时使用绝对数量。显式单位与指标不兼容时同样保留缺失，不根据数值大小猜单位。

## 自动刷新

应用处于 Activity `STARTED` 生命周期时，每 5 秒检查已缓存事件；到达公布时间后，最多 30 分钟内对缺失公布值的事件自动重试。每个日期组最多每 15 秒一次，多事件共用请求；获取公布值后停止该事件的自动重试。

直连按设备本地日期批量抓取并合并国家过滤；后端按 UTC 日期调用一次现有公布值刷新接口，再读取该日所有事件。后端日历读取强制验证网络，避免客户端 HTTP 缓存返回同步前的快照。所有标签随 Room 更新；日历页面持续观察选中的日期。

网络失败按 30／60／120 秒退避，尊重数据源已有退避及 `Retry-After`。进入后台取消刷新，恢复前台立即检查；来源切换后旧响应不能写入新缓存。自动和手动公布重试共用请求门控，成功的同日抓取有 15 秒冷却。超过 30 分钟仍无数据可使用现有手动重试。

“即时”指成功获取并保存公布值后立即更新，不保证公开数据源没有延迟。首版不新增后台常驻任务、通知内容、多国规则、历史标准化或实际走势归因。
